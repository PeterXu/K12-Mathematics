## 题目
一种汽车上用的螺丝垫圈形状如图所示,这个垫圈的直径是20mm,中间有一个边长8mm的正方形的孔。这个垫圈的面积是多少平方毫米？


![grade6_medium_hard_short_answer_c01f5239.png](images/grade6_medium_hard_short_answer_c01f5239.png)

## 解答

**答案**: 250平方毫米

1. Step1:根据垫圈直径20mm，计算其半径r，r = 20÷2 = 10毫米
2. Step2:根据圆的面积公式S圆 = πr²，计算圆的面积，S圆 = 3.14×(10×10)=3.14×100 = 314平方毫米
3. Step3:根据正方形边长8mm，计算正方形孔的面积S正，S正 = 8×8 = 64平方毫米
4. Step4:用圆的面积减去正方形孔的面积得到垫圈的面积S，S = 314 - 64 = 250平方毫米
