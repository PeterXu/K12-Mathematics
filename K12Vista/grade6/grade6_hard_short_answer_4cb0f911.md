## 题目
周五综合实践课，三年级有9个老师和42个小朋友去青少年活动中心游玩，怎样买票最合算？     


![grade6_hard_short_answer_4cb0f911.png](images/grade6_hard_short_answer_4cb0f911.png)

## 解答

**答案**: 1130

1. Step1:分析方案一，分别计算9张成人票和42张学生票的费用，成人票50元/位，学生票20元/位，费用为50×9 + 20×42 = 450 + 840 = 1290元
2. Step2:分析方案二，所有人都买团体票，总人数为9 + 42 = 51人，团体票30元/位，费用为(9 + 42)×30 = 51×30 = 1530元
3. Step3:分析方案三，让9位老师和2名学生组成11人买团体票，剩下42 - 2 = 40名学生买学生票，团体票费用为30×11 = 330元，学生票费用为20×40 = 800元，总费用为330 + 800 = 1130元
4. Step4:比较三种方案的费用1130＜1290＜1530，得出最合算的方案是方案三，费用为1130元
