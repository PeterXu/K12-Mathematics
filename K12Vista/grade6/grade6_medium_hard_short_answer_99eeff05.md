## 题目
乐乐量得下图中的圆桌桌面的直径
   是12dm．

    （1）把这张桌面一周包一圈铝合金，共需铝合金多少分米？ （接头处忽略不计）
    （2）做10张这样的圆桌面，共需多少平方米的木板？

![grade6_medium_hard_short_answer_99eeff05.png](images/grade6_medium_hard_short_answer_99eeff05.png)

## 解答

**答案**: 37.68, 11.304

1. Step1:明确问题（1）是求圆桌桌面的周长，根据圆的周长公式C = πd（其中C表示周长，d表示直径，π取3.14），已知直径d = 12dm，所以周长C = 3.14×12 = 37.68dm
2. Step2:明确问题（2）是求10张圆桌面的总面积，先根据圆的面积公式S = πr²（其中S表示面积，r表示半径），已知直径d = 12dm，半径r = 12÷2 = 6dm，所以一张圆桌面的面积S = 3.14×6² = 3.14×36 = 113.04dm²
3. Step3:计算10张圆桌面的总面积，为113.04×10 = 1130.4dm²
4. Step4:将总面积的单位由平方分米转换为平方米，因为1平方米 = 100平方分米，所以1130.4dm² = 1130.4÷100 = 11.304平方米
5. Step5:整理答案，问题（1）的答案是37.68，问题（2）的答案是11.304，得到答案列表['37.68', '11.304']
