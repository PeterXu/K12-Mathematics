# Mathematics (Grade 6)

**ID**: 347ec634
**难度**: hard
**题型**: short_answer

## 题目

（1）东东从经过学校到达公园，需要走多少米？
（2）乐乐家和红红家哪个离学校近？近多少米？
（3）你也提出一个数学问题并解答吧！

![grade6_hard_short_answer_347ec634.png](images/grade6_hard_short_answer_347ec634.png)

## 解答

**答案**: 964, 乐乐家, 172, 813

1. Step1:计算东东从家经过学校到达公园的距离，将东东家到学校的386米与学校到公园的578米相加，即386 + 578 = 964米
2. Step2:计算乐乐家到学校的距离，乐乐家到东东家427米，东东家到学校386米，两者相加427 + 386 = 813米
3. Step3:计算红红家到学校的距离，红红家到公园407米，公园到学校578米，两者相加407 + 578 = 985米
4. Step4:比较乐乐家和红红家到学校的距离，985＞813，所以乐乐家离学校近
5. Step5:计算乐乐家比红红家离学校近的距离，用红红家到学校的距离减去乐乐家到学校的距离，即985 - 813 = 172米
6. Step6:提出问题“红红去东东家需要走多远”，计算距离为红红家到乐乐家386米加上乐乐家到东东家427米，即386 + 427 = 813米
