## 题目
按下列规律印刷笑脸图案，第8副图案有（  ）个笑脸．

A．8
B．32
C．36
![grade3_medium_multiple_choice_1ce77745.png](images/grade3_medium_multiple_choice_1ce77745.png)

## 解答

**答案**: C

1. Step1:分析已知条件，由解析2可知第一幅图有1个笑脸，第二幅图有1 + 2 = 3个笑脸，第三幅图有1 + 2 + 3 = 6个笑脸，总结出规律为第n幅图中笑脸的数量是1 + 2 + 3 + … + n
2. Step2:题目要求第8副图案笑脸的数量，即当n = 8时，笑脸数量为1 + 2 + 3 + 4 + 5 + 6 + 7 + 8
3. Step3:根据解析1的计算方法，1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 =（1 + 8）+（2 + 7）+（3 + 6）+（4 + 5）= 9×4 = 36
4. Step4:得出第8副图案有36个笑脸，与选项C对应

## 知识点

**知识点**:
  - 数与形结合的规律．
