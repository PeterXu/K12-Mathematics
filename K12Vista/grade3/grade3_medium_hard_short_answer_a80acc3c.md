# Mathematics (Grade 3)

**ID**: a80acc3c
**难度**: medium_hard
**题型**: short_answer

## 题目
如图，在大正方形ABCD里有一个内接长6厘米，宽为1厘米的长方形．而且长方形的对称轴与正方形的对角线重合，求正方形的面积．

![grade3_medium_hard_short_answer_a80acc3c.png](images/grade3_medium_hard_short_answer_a80acc3c.png)

## 解答

**答案**: 24.5

1. Step1:连接BD，交中间三线EFG，根据已知条件可知图中所有三角形都是等腰直角三角形
2. Step2:因为长方形长为6厘米，所以DG和BE的长度都等于长方形长的一半，即6÷2 = 3厘米
3. Step3:计算正方形对角线的长度，为DG + BE + 长方形的宽，即3 + 3 + 1 = 7厘米
4. Step4:把正方形看成两个三角形，根据正方形面积等于对角线乘积的一半，可得正方形面积为7×7÷2 = 24.5平方厘米
