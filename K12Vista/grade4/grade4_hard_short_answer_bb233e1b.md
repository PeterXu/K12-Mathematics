## 题目
如图， ABCD是边长为5的正方形，E、F、G、H分别在边AB、BC、CD、DA上，且AE=BF=CG=DH=3，假定已知AF、BG、CH、DE围成的四边形PQRS是正方形，求图中阴影部分的面积．

![grade4_hard_short_answer_bb233e1b.png](images/grade4_hard_short_answer_bb233e1b.png)

## 解答

**答案**: $\frac{290}{17}$

1. Step1:根据勾股定理，在直角三角形AED中，已知AD = 5，AE = 3，可得ED² = AD² + AE² = 5² + 3² = 34，进而求出ED = √34
2. Step2:由平行四边形EBGD的面积关系EB×BC = ED×PQ，其中EB = 5 - 3，BC = 5，ED = √34，可求出PQ = (5 - 3)×5÷√34 = 10/√34
3. Step3:计算平行四边形EBGD的面积为(5 - 3)×5
4. Step4:计算平行四边形AFCH的面积为(5 - 3)×5
5. Step5:计算正方形PQRS的面积为(10/√34)²
6. Step6:根据S阴 = S_{EBGD} + S_{AFCH} - S_{PQRS}，可得S阴 = (5 - 3)×5 + (5 - 3)×5 - (10/√34)² = 10 + 10 - 50/17 = 290/17
