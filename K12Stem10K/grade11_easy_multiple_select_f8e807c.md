## 题目
已知a，b为不垂直的异面直线， $α$ 是一个平面，则a，b在 $α$ 上的射影有可能是（      ）​​​​​​​‌

## 解答

1. 解：不妨以正方体为例， $A{{}_{1}}D$ 与 $BC{{}_{1}}$ 在平面ABCD上的射影互相平行，A正确；
2. $AB{{}_{1}}$ 与 $BC{{}_{1}}$ 在平面ABCD上的射影互相垂直，B正确；
3. 如果a、b在 ${\rm \mathit{α}}$ 上的射影是同一条直线，那么a、b共面，C不正确．
4. $DD{{}_{1}}$ 与 $BC{{}_{1}}$ 在平面ABCD上的射影是一条直线及其外一点，D正确．
5. 故选ABD．
